# pdf2epub (Aldleaf)

This is a shortcut name for the **aldleaf** skill in this plugin. Load the `aldleaf` skill and follow its instructions exactly, from "0. Rights and privacy first" through "4. Deliver", for the user's PDF book.

Aldleaf reads PDF files only. If the user has a Word, Pages, Google Docs or other editor file, ask them to export their final, edited, print-ready version as a PDF first.
